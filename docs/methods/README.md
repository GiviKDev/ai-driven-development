# Methods

Detailed specifications for specific quality methods
referenced from the practice documents in
[practices/](../practices/).

Each method has its own folder with a README and
supporting documents.

## Contents

- [journey-verification/](journey-verification/) --
  walking a system through defined user journeys on
  the callable surface and evaluating each step
  against binary criteria.
- [trace-analyzer/](trace-analyzer/) -- analyzing
  distributed traces against budgets using an MCP
  server.
- [observability-signals/](observability-signals/) --
  reference tables for trace, log, and metric
  findings during development-time verification.
