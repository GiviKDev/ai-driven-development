# Agents

Standalone AI agent samples (`.agent.md` files).
Each file defines a specialized agent with a
narrow scope, listed tools, and communication
rules.

This folder is a catalog of reusable samples.
Agents that work together with skills belong in
`plugins/` instead.

This is not an active tool-discovery location. To
make an agent active in a project, place it under
`.github/agents/`, `.claude/agents/`, or a plugin's
`agents/` directory.

Use an agent when the work needs a specialized role,
tool restrictions, context isolation, or handoff to
another role. Use a skill for a reusable procedure
that does not need a separate persona.

Currently empty. Samples will be added as they
emerge from real projects.
