# Prompts

Prompt file samples. Each file defines a reusable
prompt that can be invoked by name in a compatible
AI tool.

This folder is a catalog of reusable samples.

This is not an active prompt-discovery location. To
make a prompt active in a project, place it in the
prompt location your tool supports.

Use prompts for focused, repeatable tasks with clear
inputs. Do not use long prompts as project memory;
stable context belongs in docs, instructions, skills,
or plugins.

Currently empty. Samples will be added as they
emerge from real projects.
